# Requirements reader

Responsive Kazakh-language book reader with synchronized contents, search, bookmarks and Google Forms link.

Adapted from https://github.com/AFRICA1525/E-reader. PDF.js copyright Mozilla Foundation, Apache-2.0; original notices retained in vendor files. No new license is asserted for the upstream code or textbook.

This repository contains only public site assets. The PDF and search text are public and downloadable. No author account, upload API or backend is deployed.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). HTTPS is provided on the github.io address. The HTML includes a CSP; Node server headers, frame-ancestors and request limits do not apply on GitHub Pages.
